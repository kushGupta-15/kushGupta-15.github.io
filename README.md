## 🚀 How to Run Locally

### Option 1: Direct File Open
Double-click `index.html` in Windows File Explorer to view in any modern browser.

### Option 2: Local HTTP Server
```bash
npx serve .
# or
python -m http.server 3000
```
Open `http://localhost:3000` in your browser.
